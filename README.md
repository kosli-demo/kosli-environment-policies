# kosli-environment-policies

Github Action pipeline yaml to create [Kosli](https://docs.kosli.com/) compliance policies and attach them to the kosli-demo staging environment on both
- [app.kosli.com](https://app.kosli.com/kosli-demo/environments/staging/snapshots/), and
- [staging.app.kosli.com](https://staging.app.kosli.com/kosli-demo/environments/staging/snapshots/)
